# Creative Frontend Direction

This skill establishes visual identity, intentional layout compositions, art direction, and brand cohesiveness across all interface screens.

## Core Directives

1. **Purposeful Visual Hierarchy**: Every screen must have a clear visual focal point, logical typographic scale, and intentional negative space.
2. **Distinctive & Non-Generic**: Avoid generic templates, random gradient overlays, or meaningless visual clutter. Every design decision must serve the product domain.
3. **Cohesive Color Harmony**: Adhere strictly to the defined semantic color tokens (primary, surface, error, text contrast).
4. **Content-First Composition**: Structure layouts around real user workflows and crisis-response needs (for disaster relief: high legibility, urgent callouts, clear status).

## Verification Checklist

- [ ] Clear visual hierarchy on every screen.
- [ ] Typography scale consistent across all activities.
- [ ] Contrast meets WCAG AA standards.
